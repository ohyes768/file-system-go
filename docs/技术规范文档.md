# 文件服务器技术规范文档

## 1. 项目概述

### 1.1 项目名称
Go File Server（v2.0.0）

### 1.2 项目目标
基于 Go 语言开发的轻量级文件存储服务，用于在阿里云 ECS 服务器上托管任意类型的文件（视频/音频/图片等）。**v2.0 定位为纯文件存储**，不管理业务元数据和用户行为状态——这些由上层应用（如 douyin-processor）维护。

### 1.3 技术选型理由
- **Go 语言**: 单文件部署、高性能、跨平台、低资源占用
- **Gorilla Mux**: 强大的 HTTP 路由器
- **YAML 配置**: 灵活的配置管理
- **双日志输出**: 控制台 + 文件日志
- **HTTP Range 标准**: 下载走 `http.ServeContent` 自动支持断点续传

## 2. 需求分析

### 2.1 功能需求

#### 2.1.1 核心功能（v2.0.0）
1. **健康检查接口**
   - 路径: `GET /health`
   - 响应: 服务状态、版本号、存储目录

2. **文件上传接口**
   - 路径: `POST /api/files`
   - 功能: 接收 multipart/form-data 格式的文件上传
   - 限制: 最大 `config.max_upload_mb`（默认 100MB）
   - 响应: 上传成功后的文件名、URL、大小
   - 字段: 仅 `file`，**不接收业务元数据**（v1.x 的 title/author/description 已废弃）

3. **文件下载接口**
   - 路径: `GET /api/files/{id}/download`
   - 功能: 按文件 ID 下载，支持 HTTP Range
   - ID 规则: 上传时的客户端文件名（含扩展名）

4. **文件删除接口**
   - 路径: `DELETE /api/files/{id}`
   - 功能: 硬删除（直接 `os.Remove`，不保留软删除记录）

5. **文件列表查询接口**
   - 路径: `POST /api/files/query`
   - 功能: 列出存储目录文件，支持 prefix/suffix 过滤

6. **静态文件服务（旁路）**
   - 路径: `/audio/{filename}`
   - 功能: 浏览器直连，无需走 API

#### 2.1.2 已剥离业务（v2.0.0 移除）
以下功能 v1.4/v1.5 实现过，v2.0 迁出至 douyin-processor：
- ~~文件元数据管理~~（title/author/description + .meta.json 存储）
- ~~文件检查接口~~（查重）
- ~~已删除文件记录~~（软删除/防重推）
- ~~已读文件管理~~
- ~~取消收藏文件管理~~

#### 2.1.3 非功能性需求
1. **性能**: 高并发文件上传和下载
2. **可靠性**: 日志记录、错误处理、服务自动重启
3. **可维护性**: 清晰的代码结构、配置文件管理
4. **可部署性**: 单文件部署、交叉编译支持

### 2.2 约束条件
- Go 版本: 1.21+
- 部署环境: Linux AMD64 (阿里云 ECS)
- 本地开发: Windows 环境
- 配置管理: YAML 配置文件
- 日志输出: 控制台 + 文件 (logs/ 目录)
- Go 代理: 国内环境使用 GOPROXY 加速依赖下载

### 3.3 接口设计（v2.0.0）

#### 3.3.1 健康检查接口
- **方法**: GET
- **路径**: `/health`（v1.x 是 `/`）
- **请求**: 无
- **响应**:
  ```json
  {
    "service": "File Server (Go)",
    "status": "running",
    "version": "2.0.0",
    "audio_dir": "/var/www/audio"
  }
  ```

#### 3.3.2 文件上传接口
- **方法**: POST
- **路径**: `/api/files`（v1.x 是 `/upload`）
- **请求**: multipart/form-data
  - 字段名: `file`
  - 文件类型: 任意（不再限定 audio/*）
- **成功响应** (200):
  ```json
  {
    "success": true,
    "filename": "video123.mp4",
    "url": "/api/files/video123.mp4/download",
    "size": 12345
  }
  ```
- **失败响应** (400/500):
  ```json
  {
    "success": false,
    "error": "错误描述"
  }
  ```
- ⚠️ v1.x 的 `title` / `author` / `description` 字段已废弃

#### 3.3.3 文件下载接口
- **方法**: GET
- **路径**: `/api/files/{id}/download`（v1.x 是 `/api/videos/{id}/download`）
- **路径参数**:
  - `id`: 文件 ID（= 上传时的客户端文件名，含扩展名）
- **响应**: 文件二进制流，**支持 HTTP Range**（断点续传）
- **响应头**:
  - `Content-Type` 按扩展名推断
  - `Content-Length` / `Content-Disposition` / `Last-Modified` / `ETag` / `Accept-Ranges: bytes`
- **失败响应**: 400（路径遍历字符）、404（文件不存在）

#### 3.3.4 文件删除接口
- **方法**: DELETE
- **路径**: `/api/files/{id}`（v1.x 是 `/api/file/{filename}` + `/api/videos/{filename}` 双路径）
- **路径参数**:
  - `id`: 文件 ID
- **行为**: 硬删除（直接 `os.Remove`，**不**写入任何 records）
- **成功响应** (200):
  ```json
  {
    "success": true,
    "message": "File deleted successfully"
  }
  ```
- **失败响应**: 400 / 404 / 500

#### 3.3.5 文件列表查询接口
- **方法**: POST
- **路径**: `/api/files/query`（v1.x 是 `/api/videos/query`）
- **请求体**:
  ```json
  {
    "filters": {
      "prefix": "douyin_",
      "suffix": ".mp4"
    }
  }
  ```
- **成功响应** (200):
  ```json
  {
    "success": true,
    "videos": [
      {
        "id": "douyin_video1",
        "filename": "douyin_video1.mp4",
        "size": 102400000,
        "url": "/audio/douyin_video1.mp4"
      }
    ]
  }
  ```
- **失败响应**: 400（请求体非法）、500（读目录失败）

#### 3.3.6 静态文件访问（旁路）
- **方法**: GET
- **路径**: `/audio/{filename}`
- **响应**: 文件二进制内容
- **实现**: Go 标准 `http.FileServer` + `http.StripPrefix`
- **保留原因**: 浏览器直连、CDN 友好

## 5. 技术实现

### 5.1 依赖包
```go
require (
    github.com/gorilla/mux v1.8.1          // HTTP 路由
    gopkg.in/yaml.v3 v3.0.1                // YAML 解析
)
```

### 5.2 关键技术点

#### 5.2.1 配置管理
- 使用 `gopkg.in/yaml.v3` 解析 YAML 配置
- 环境变量覆盖支持 (可选)
- 配置热加载 (不实现,保持简洁)

#### 5.2.2 日志系统
- 使用标准库 `log` 包
- 自定义 `io.MultiWriter` 实现双输出
- 日志文件按日期轮转

#### 5.2.3 文件上传
- 使用 `http.MaxBytesReader` 限制大小
- `r.ParseMultipartForm()` 解析表单
- `io.Copy` 高效复制文件
- 错误处理和资源清理 (defer Close)

#### 5.2.4 静态文件服务
- 使用 `http.FileServer`
- `http.StripPrefix` 去除路径前缀
- 支持范围请求 (断点续传)

#### 5.2.5 中间件
- 日志中间件: 记录请求方法、路径、来源、耗时
- 恢复中间件: 捕获 panic,防止服务崩溃
- CORS 中间件 (可选)

#### 5.2.6 Go 代理配置（国内环境）
- **问题**: 国内访问 `proxy.golang.org` 速度慢或超时
- **解决方案**: 配置国内 Go 代理镜像
- **推荐代理**:
  - 七牛云: `https://goproxy.cn`
  - 阿里云: `https://mirrors.aliyun.com/goproxy`
- **配置方式**:
  ```bash
  # 临时配置
  export GOPROXY=https://goproxy.cn,https://mirrors.aliyun.com/goproxy,direct
  export GO111MODULE=on

  # 永久配置（添加到 ~/.bashrc）
  echo 'export GOPROXY=https://goproxy.cn,direct' >> ~/.bashrc
  source ~/.bashrc
  ```
- **编译脚本自动化**: `scripts/build.sh` 和 `scripts/build-test.sh` 已内置 GOPROXY 配置

### 7.3 systemd 服务配置
```ini
[Unit]
Description=Audio File Server (Go)
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/audio-server
ExecStart=/root/audio-server
Restart=always
RestartSec=5s
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```
